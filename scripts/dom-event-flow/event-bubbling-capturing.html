Event Bubbling vs. Capturing

Events traverse the DOM in two phases when an element is clicked:

  • Capturing Phase: Trickles down from Window -> Grandparent -> Parent -> Child.
  • Bubbling Phase: Bubbles back up from Child -> Parent -> Grandparent -> Window.
